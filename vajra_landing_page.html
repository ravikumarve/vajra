The default approach of baking API keys into `.env` files is a security disaster waiting for a prompt injection. Static credentials mean one leak equals total compromise.

01 // Zero Standing Privilege

Sub-5s Ephemeral Credentials

Credentials exist only when needed. The in-memory ring buffer mints, issues, and sweeps credentials in under 5 seconds. If an agent is hijacked, the key is already dead.

02 // OPA/Rego Engine

Strict ABAC Policies

Implement row-level, column-level, and API-scoped boundaries using industry-standard Open Policy Agent (OPA/Rego). No custom DSLs to learn.

03 // Immutability

SQLite Audit Trail

Every mint, use, and expiry is logged to an embedded, append-only SQLite database. Stream logs via JSON stdout to your SIEM.

04 // Developer Experience

Command Line Control

Mint scoped credentials manually, test OPA policies, and monitor the credential stream directly from your terminal.

# Mint a scoped credential manually
$ ./vajra mint --db customers --ttl 5s --select "email,name"

# Watch live credential stream
$ ./vajra ps
